## 五个案例的交汇：Rust 竞争力的完整光谱

1. **机制对问题的精确映射**：每个 C/C++ 经典失败模式都有对应的语言机制承接——引用计数配对→`Drop`/`ManuallyDrop`（01）；协议状态机→带数据的枚举（02）；悬垂回调→`WeakBox`（03）；跨语言所有权→生命周期参数（04）；资源配对→RAII（05）。不是"内存安全"一句空话，而是逐条对照。
2. **竞争力的双向精确**：要跨线程就 `Send + Sync` 编译期证明（01）；不跨线程就把 `?Send` 写进类型、用单线程 async 消解竞争（03）。Rust 不是"默认更安全"，是"并发假设可被表达和检查"。
3. **unsafe 是审计杠杆而非漏洞**：五个库的 unsafe 全部贴 FFI/syscall 边界且带 SAFETY 论证——审计面从全库压缩到边界点（03 甚至为零），但边界点仍需专家 review。CrabbyAVIF 未遂事件说明 unsafe 内依然可能写错。
4. **语言外四条腿**：AIDL 稳定接口（02 透明替换）、Mainline APEX 分发（03 周级下发）、Soong 原生构建（05 零额外成本）、bindgen/cxx 互操作（01/04 的封装层）。Rust 从不单独作战。
5. **从安全工具到默认语言**：01-04 是安全驱动的胜利，05 是效率驱动的投票——合起来说明 Rust 在 AOSP 已完成"专项工具 → 平台默认语言"的跃迁。
