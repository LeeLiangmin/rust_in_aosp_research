# AOSP Rust 相关仓库分类

来源：android.googlesource.com（官方仓库清单 + 顶层结构 + README，本目录爬取归档于 aosp_tree.db）。
分类口径：**内部库**＝Google 为 Android 系统开发的 Rust 模块；**共享外部**＝Google 维护、托管于 external/、供 Android 及其它项目共用的开源组件；**第三方**＝上游 crate/工具，AOSP 仅 vendor。
链接：表中 repo 名均链接到 android.googlesource.com 仓库；第三方 crate 行另附 crates.io 链接。
语言构成：对每仓库源码快照统计文件扩展名得出——纯 Rust（仅 .rs）；Rust 为主（≥90%）；混合（含较多 C/C++/Java/Kotlin/Go）；非 Rust 主体（如 soong 为 Go）。

## 总览

- 含 Rust 信号的仓库：504（其中 external/rust/crates 第三方 crate 有源码的 430 个）
- 内部库（Android 系统自有）：**46**
- 共享外部（Google 维护开源）：**21**
- 第三方（上游 vendor）：**437**

**语言构成（内部+共享仓库，按源码文件统计）**：混合 32 个；Rust 为主 14 个；纯 Rust 12 个；空仓库/受限（无源码） 5 个；非 Rust 主体 4 个
